US States REST API

A REST API providing data on the 50 US states, backed by Node.js, Express, and MongoDB.

Endpoints

GET

  • /states/ — all state data
  • /states/?contig=true — contiguous states (excludes AK and HI)
  • /states/?contig=false — non-contiguous states (AK and HI)
  • /states/:state — data for one state
  • /states/:state/funfact — random fun fact
  • /states/:state/capital
  • /states/:state/nickname
  • /states/:state/population
  • /states/:state/admission

POST / PATCH / DELETE

  • POST /states/:state/funfact — body: { "funfacts": ["fact1", "fact2"] }
  • PATCH /states/:state/funfact — body: { "index": 1, "funfact": "new text" }
  • DELETE /states/:state/funfact — body: { "index": 1 }

The :state parameter is a two-letter state code (e.g. KS, NE, TX).
